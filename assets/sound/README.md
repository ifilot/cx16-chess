# Chess audio

Generated by the local `chipscore` Chess project on 2026-10-11. These copies
make this repository build independently of the neighbouring project.
`manifest.json` records source-file sizes and SHA-256 hashes.

The source is `chipscore/assets/chess/project.yaml` in the sibling repository.
To update, build that project with `bin/chipscore project assets/chess/project.yaml`,
then copy its `build/chess/psg/*.ZSM`, `SFX.BIN`, `music.h`, and `sfx.h` here
and refresh the manifest. The generated bank assignments must start at 26,
end below 44, and keep each effect inside bank 25.

The title is *The Gambit*. New games rotate through *Opening Theory*,
*Sarabande*, *Café de la Régence*, and *Nocturne*. WIN, LOSE, and DRAW are
one-shot result jingles. Music uses PSG voices 0–11; effects own 12–15.

The game uses the vendored ZSMKit memory player with streaming disabled.
Its source and MIT license are in `src/vendor/zsmkit`. The library resides
in low RAM; state occupies bank 44 and the audio controller occupies bank 45.
Bank 23 remains the board/menu helper bank. No audio file is opened during play.

`python3 tools/audio_test.py` checks every loaded byte, compares actual PSG
registers with the decoded assets through complete tracks/loops and all effects,
and checks playback while the engine searches.

The game build packs these source tracks and effects, together with banked
code, into `CHESS.BIN`. Releases do not need the individual audio files.
